# Заметки

Отдельный плагин Shtab: список, поиск, закрепление, редактор и безопасный
Markdown-просмотр. Стиль и обе темы наследуются от ядра.

Личные заметки видит и редактирует только владелец. Общие видят все пользователи.
Администратор и доверенные пользователи могут редактировать общие заметки и
публиковать в общие свои личные. Публикация переносит заметку в корень общего раздела.

Заметки и папки сохраняются в базе ядра. При первом открытии личного раздела
плагин переносит заметки и папки из этого браузера. Выполните миграцию заметок
после миграций ядра с тем же `SHTAB_DATABASE_URL`:

```powershell
uv run --all-packages python -m shtab_notes.migrate upgrade head
```

Установка: `POST /api/plugins` с содержимым `manifest.json` (`url: local:notes`).
Для установки из GitHub передайте в запросе URL репозитория в поле `url`.
Исходник — `notes/`, установленная копия — `core/plugins/notes/`.
Страница: `/plugins/notes`, диагностический API: `/api/plugins/notes/health`.

Markdown: заголовки, жирный/курсив, списки и чек-листы, ссылки, цитаты и блоки кода.
HTML в заметках отображается текстом; ссылки допускают только HTTP, HTTPS и mailto.
